# Bootstrap

Objetivo: fundação segura e verificável sem domínio financeiro. Resultado: workspace Next.js, PostgreSQL/Drizzle, Better Auth, shell, temas, PWA conservadora, Docker, testes e documentação criados. Verificações concluídas: agentes, tipos, lint, unitário, integração PostgreSQL, migração/seed, build, imagem Docker e integridade de migração. Limitação conhecida: navegadores Playwright requerem dependências de sistema indisponíveis neste ambiente sem sudo; a suíte permanece configurada para CI.
