# Matriz

Login, tema, shell, logout, offline e manifesto: E2E Chromium; WebKit: compatibilidade reduzida. Banco: migração e isolamento. A11y: axe em login, shell e offline.

CLI administrativa: integração contra PostgreSQL real, executando processos filhos para criação, listagem, reset de senha, revogação de sessões, validações de ambiente, auditoria e ausência de senha na saída. Health: teste unitário do handler para readiness e resposta 503 sem detalhes de conexão. PWA: Chromium confirma o registro/controlador do service worker, shell público em Cache Storage e limpeza de armazenamento privado no logout.
