# Modelo conceitual futuro

Auditoria e preferências são independentes e as preferências pertencem diretamente ao usuário. Dispositivo e assinatura Push continuam extensões futuras do contrato de notificações. Simulação e importação são futuras. Criado por não é responsável financeiro.
