# Recorrência

Regra imutável por versão; exceção pode alterar somente uma ocorrência ou cortar série para próximas. Ao mudar a data de uma série, a data da ocorrência selecionada (`effectiveFrom`) é separada da nova âncora da primeira ocorrência futura. Assim, uma ocorrência em 07/08 pode ser substituída por 05/08 sem exigir que 05/08 exista na regra anterior. Ocorrências históricas não são reescritas: ao criar uma versão futura, somente ocorrências pendentes a partir da data efetiva são canceladas e rematerializadas. Recorrência mensal calcula cada ocorrência a partir da âncora original para preservar dias 29, 30, 31 e fim de mês. Séries ativas são materializadas idempotentemente até o horizonte anual do painel.
